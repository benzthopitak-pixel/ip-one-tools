ติดตั้ง AssetSync

แอปตรวจนับทรัพย์สินสำหรับเครื่องสแกน Android
ดาวน์โหลดแอป (.apk)

ติดตั้งบนเครื่องสแกน

  1. เปิดหน้านี้ใน Chrome บนเครื่องสแกน แล้วกดปุ่มดาวน์โหลดด้านบน
  2. แตะไฟล์ ams-count.apk ที่ดาวน์โหลดเสร็จ
  3. ถ้าเครื่องถาม "อนุญาตให้ติดตั้งแอปจากแหล่งนี้" ให้เปิดอนุญาตสำหรับ Chrome
  4. ถ้ามีคำเตือนจาก Play Protect ให้กด "ติดตั้งต่อ" (แอปของบริษัทเอง ไม่ได้อยู่ใน Play Store)
  5. เปิดแอป AssetSync แล้วเข้าสู่ระบบด้วยรหัสพนักงาน + PIN

อัปเดตเวอร์ชันใหม่: ดาวน์โหลดแล้วติดตั้งทับได้เลย ผลนับในเครื่องไม่หาย

เปิดหน้านี้บนเครื่องสแกน

สแกน QR นี้ด้วยเครื่องสแกน (ลิงก์จะพิมพ์ลงช่องที่อยู่ของ Chrome) หรือสแกนด้วยกล้อง

ไม่มีอินเทอร์เน็ต?

ดาวน์โหลดไฟล์ .apk บนคอมพิวเตอร์ → ต่อสาย USB → ก๊อปไปไว้ใน Download ของเครื่องสแกน → เปิดแอป Files บนเครื่องสแกนแล้วแตะไฟล์

ตั้งค่าเครื่องสแกน CipherLab

ReaderConfig → Output → Keyboard Emulation · Suffix = Enter (ขึ้นบรรทัดใหม่) · เปิดอ่าน QR Code และ Code 128

กลับไปหน้าเว็บ AssetSync
